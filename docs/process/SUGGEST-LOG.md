1. **采纳的门槛**：建议必须同时满足（a）不增加子代理提示词长度超过一行；（b）不违背三条核心纪律（只读两个目录 / 视觉直读 / 不放大）；（c）能用校验器或编排者脚本兜底的就不进提示词。
